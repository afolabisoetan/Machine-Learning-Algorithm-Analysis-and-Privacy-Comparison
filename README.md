This study compares the efficacy of each classifier for correctly recalling fraudulent credit card activity. The classifiers are tested on a data set containing only PCA (Principal Component Analysis) -transformed values (columns V1-V28) and a data set containing PCA-transformed value columns in addition to human readable columns  (amount and time). The purpose of this study is to verify whether the cost of having the data set include the human readable columns is worth it. Including human readable columns sacrifices data minimization and anonymization since knowing the time of a fraud and the amount that was flagged can provide someone clues and dots to connect to possibly identify that transaction and the victim (linkage risk). Thus, justifying the inclusion of these columns can only be proven by showing that they actually provide a statistically significant advantage in the classifiers’ ability to identify fraudulent activity in such a way that justifies the reduced data minimization, anonymity, and privacy.
